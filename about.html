ABOUT

Models

For this website I created three spaceship models in Blender. Two of these take inspiration from star wars (Lambda Shuttle and Tie Fighter) one is my own design. I used a range of Blender techniques in this process. The modifiers I used the most where boolean, subdivision surface, bevel, and mirror.
I also spent a lot of time making procedural textures in the shader editor for my models to create convincing materials for the spaceships. Using a mix of noise and musgrave nodes and editing the outputs of these created a nice worn metallic effect for my models. As the GLB file format does not support complex texutures the UVs had to be unwrapped and the textures baked into an image before the models could be exported. Effects such as roughness and metallic on the principled BSDF where still utilised.

Design

The website follows a retro sci-fi aesthetic, taking inspiration from late 00s and early 2010s web design. I used a range of bootstrap components and custom CSS styling to achieve this effect. The 3D scenes use both a direct and ambient light source.

Intergration

The whole website is responsive, working well on both desktop and mobile window sizes, different UI elements on different pages are resized accordingly. Images are resized to fit the page correctly depending on window size. Sounds are present on both Model and Free Fly pages. On the free fly page, the sound of the spaceship engine changes depending on the movement of the ship (direction / boost).

Interaction

On the model page, alongside the HTML buttons to change the state of the canvas, the user can look around the scene using the standard ThreeJS orbit controls. On the Free Fly page, the user can use the WASD keys to control the spaceship, press SHIFT to speed the spaceship up, and press the 1, 2, and 3 keys on the keyboard to change the spaceship model. The spaceship controls are intuiative and works similarly to other spaceship-flying video games.

Implementation

I have tested this website both on my own laptop and on a lab computer to ensure everything works correctly on different machines. I have also conducted user testing , recieving feedback from both a technical and non-technical audience. Some feedback I received:

  • "The lighting is too dark" (as a result of this I increased light levels in the scene)
  • "I really like the cyberpunk visuals"
  • "I found the controls [on the Free Fly page] hard at first, but they made sense after I got used to them"

Deeper Undestanding

The Free Fly page offers a simple interactive gameplay experince where the user can fly a spaceship through a sci fi city. This involves handling input, sound feedback, a lot of linear interpolation, and procedural animation. I leveraged object-oriented javascript techniques to abstract out the player into a class.
I used various post-processing effects, using the ThreeJS EffectComposer. The 3D modelling complexity and techniques used also go beyond that which was taught in the labs.
